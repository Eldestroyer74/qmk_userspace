Two-Screen Wireframe

Shared vocabulary for the minimal update. Put the status/discovery screen on the left OLED because the anchors and chords happen on the left hand. Move Bongocat to the right OLED. Keep the current status screen structure: logo at the top, the existing layer tile in the middle, and a 2x2 bottom stack. The proposed change is to make that bottom stack reflect the home-row concepts instead of the current modifier labels. When a home-row concept is held, its slot appears on and the middle tile changes to the anchor image. When a chord is pressed, the same fixed slot changes to the chord image. The first scaled right-screen label worked, but it was slow; prefer replacing the small corne text slot with lowercase state names such as nav, styles, snap, span, or caps.

Screen Role Swap the roles: left OLED becomes the status/discovery screen because left-hand anchors and chords drive it; right OLED keeps Bongocat.
Logo Region Current top logo area. Keep it where it is; held home-row state should make the relevant mark look on.
Layer Tile Current Base/Numbers/Symbols icon area. It stays in the current position, but the image changes from Base to Anchor to Chord as the state deepens.
Home-Row 2x2 Status Stack Use the current bottom 2x2 modifier-stack grammar. The labels/concepts change from modifiers to home-row states.
Chord Label Do not use the slow full-screen scaled label path next. Reuse the existing small text slot where corne appears and show lowercase state names there.
Open Question Which four home-row concepts map to the 2x2 stack positions, and can their on/off states reuse the existing modifier-stack visual grammar?

Actual Layer Tile Images

The firmware does not move one Base image through the states. It has three named image strings in oled/oled-icons.c, and render_layer_state() chooses between them: base_layer for resting typing, anchor_layer for home-row holds, and chord_layer for chorded layers. The slot stays fixed; the image changes.

base_layer

Glyphs: 9a 9b 9c / ba bb bc / da db dc. Used by default, including Base and Colemak.

anchor_layer

Glyphs: 94 95 96 / b4 b5 b6 / d4 d5 d6. Reused from the old Numbers tile for home-row anchor holds.

chord_layer

Glyphs: 97 98 99 / b7 b8 b9 / d7 d8 d9. Reused from the old Symbols tile for chorded layers.

Use Now

The status renderer, layer/modifier split, custom font approach, and tap timer are useful immediately. They match the goal: feature discovery without inventing a new firmware architecture.

Use Carefully

Bongocat and Luna prove the animation path, but their art is expensive. Reuse their structure only after a smaller status screen fits.

Design Question

Should the first OLED screen show exact key positions, or should it show the current concept and the next possible gestures? The current evidence points toward concept plus next actions.
